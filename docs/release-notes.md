## Tasks 0.2.0

- Check for updates from the Tasks menu or Settings → Updates.
- Optional automatic checks on launch and every six hours, with a quiet availability notice.
- Review release notes, download a cryptographically verified update, then choose Install and restart.
- Installation waits for pending changes in every window and native file operation. Failed saves cancel installation and keep your drafts.
- Universal macOS download for Apple Silicon and Intel, plus installation through `brew install --cask dwennk/tap/tasks`.

Tasks remains in early development. This release adds the update mechanism for future releases; users of 0.1.0 need to install 0.2.0 once manually. Personal cloud sync still requires provider configuration and real-account verification.
